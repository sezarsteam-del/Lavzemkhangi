# اپلیکیشن اندروید لوازم خانگی

این پروژه یک اپلیکیشن Android بومی با Kotlin و WebView است که فروشگاه
https://lavzemkhangi.ethiodeploy.app/ را باز می‌کند.

## ساخت APK
1. پوشه `android` را در Android Studio باز کنید.
2. از JDK 17 و Android SDK Platform 35 استفاده کنید.
3. Gradle Sync و سپس Build > Build APK(s) را اجرا کنید.

همچنین با اجرای GitHub Actions و workflow با نام **Build Android APK**،
فایل APK آزمایشی به‌صورت Artifact قابل دریافت خواهد بود.

## اعلان‌های پس‌زمینه
مجوز اعلان اندروید در نسخه فعلی درخواست می‌شود، اما ارسال اعلان هنوز فعال نیست.
برای فعال‌سازی واقعی باید یک پروژه Firebase ایجاد شود، فایل `google-services.json`
در مسیر `android/app/` قرار گیرد، Firebase Cloud Messaging به برنامه افزوده شود
و توکن دستگاه به یک API امن در سرور Flask ثبت شود. کلیدهای محرمانه Firebase
و سرویس‌اکانت نباید در مخزن عمومی قرار گیرند.

## امنیت
WebView فقط دامنه فروشگاه را داخل برنامه نگه می‌دارد؛ لینک‌های HTTP/HTTPS خارجی
در مرورگر دستگاه باز می‌شوند. دسترسی فایل، محتوای محلی، مکان‌یابی و محتوای ترکیبی
غیرفعال است. خطاهای گواهی TLS نباید نادیده گرفته شوند.
