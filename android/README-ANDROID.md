# اپلیکیشن اندروید اختصاصی لوازم خانگی

این برنامه یک اپلیکیشن بومی Android با Kotlin است؛ از WebView استفاده نمی‌کند.
رابط کاربری تیره و طلایی است و داده‌ها را از API امن Flask فروشگاه دریافت می‌کند.

## امکانات پیاده‌سازی‌شده
- فهرست دسته‌بندی‌ها و محصولات واقعی فروشگاه
- جست‌وجوی محصولات و فیلتر دسته‌بندی
- نمایش قیمت و تصویر محصول
- سبد خرید داخل برنامه
- ثبت‌نام و ورود مشتری با شماره موبایل و رمز عبور
- ذخیره توکن ورود با رمزنگاری Android Keystore
- ثبت سفارش بدون پرداخت آنلاین و با وضعیت «در انتظار تأیید فروشگاه»
- مشاهده سفارش‌های قبلی مشتری
- ذخیره سفارش‌ها در جدول‌های مشترک فروشگاه و نمایش در پنل مدیریت فعلی

## API
مسیر پایه: `/api/android/v1`

- `GET /health`
- `GET /categories`
- `GET /products`
- `POST /auth/register`
- `POST /auth/login`
- `POST /auth/logout`
- `GET /me`
- `GET /orders`
- `GET /orders/<id>`
- `POST /orders`

درخواست‌های محافظت‌شده از توکن Bearer استفاده می‌کنند. توکن خام در پایگاه داده ذخیره نمی‌شود؛ فقط هش آن نگهداری می‌شود.

## ساخت APK
1. پوشه `android` را در Android Studio باز کنید.
2. از JDK 17 و Android SDK Platform 35 استفاده کنید.
3. Gradle Sync و سپس Build > Build APK(s) را اجرا کنید.

GitHub Actions نیز با هر push تغییرات پوشه `android/**`، workflow با نام **Build Android APK** را اجرا می‌کند. پس از موفقیت، Artifact با نام `lavzemkhangi-android-debug` قابل دریافت است.

## مواردی که برای فعال‌سازی کامل هنوز نیازمند تنظیم بیرونی‌اند
- اعلان Push واقعی در پس‌زمینه: ساخت پروژه Firebase، افزودن `google-services.json` و پیکربندی Firebase Cloud Messaging و ثبت توکن دستگاه روی سرور لازم است. مجوز اعلان به‌تنهایی به معنی فعال بودن Push نیست.
- نسخه فعلی سفارش را بدون پرداخت آنلاین و در وضعیت انتظار تأیید ثبت می‌کند.
