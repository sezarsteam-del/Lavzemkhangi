# فروشگاه لوازم خانگی

وب‌سایت فارسی راست‌چین برای نمایش فهرست قیمت محصولات و مدیریت دسته‌بندی‌ها و محصولات.

## امکانات
- نمایش عمومی دسته‌بندی‌ها و محصولات
- جست‌وجوی محصول و دسته‌بندی
- پنل ورود مدیر
- افزودن، ویرایش و حذف دسته‌بندی
- افزودن، ویرایش و حذف محصول
- ذخیره اطلاعات در PostgreSQL

## راه‌اندازی روی Render
1. فایل ZIP را استخراج و همه فایل‌ها را در یک مخزن GitHub بارگذاری کنید.
2. در Neon یک دیتابیس PostgreSQL رایگان بسازید و connection string را بردارید.
3. در Render گزینه New > Blueprint را بزنید و مخزن GitHub را متصل کنید.
4. متغیرهای محیطی را تنظیم کنید:
   - `DATABASE_URL`: آدرس اتصال Neon
   - `ADMIN_USERNAME`: نام کاربری مدیر دلخواه
   - `ADMIN_PASSWORD`: رمز عبور قوی و غیرقابل حدس
   - `SECRET_KEY`: یک مقدار تصادفی طولانی (Render می‌تواند آن را بسازد)
5. Deploy کنید. جدول‌ها در اولین درخواست ساخته می‌شوند.
6. برای ورود به پنل، به آدرس `/login` بروید.

## نکات امنیتی
- رمز مدیر را در کد قرار ندهید؛ فقط در Environment Variables سرویس Render وارد کنید.
- مقدار `SECRET_KEY` را تغییر دهید و محرمانه نگه دارید.
- این نسخه آدرس اینترنتی تصویر را می‌پذیرد؛ آپلود مستقیم فایل تصویر هنوز پیاده‌سازی نشده است.
- پلن رایگان Render ممکن است سرویس را پس از بی‌کاری متوقف کند. Neon و Render محدودیت‌های پلن رایگان خود را دارند.
