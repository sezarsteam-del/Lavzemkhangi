# فروشگاه لوازم خانگی

سامانه فروش و مدیریت فروشگاه لوازم خانگی با Flask و PostgreSQL.

## امکانات فروشگاه
- جست‌وجو و فیلتر محصولات بر اساس برند و بازه قیمت، مرتب‌سازی
- صفحه اختصاصی محصول، محصولات مشابه، پرسش‌وپاسخ و نظرات خریداران
- حساب مشتری، سبد خرید، نشانی‌ها، سفارش اینترنتی و پیگیری
- علاقه‌مندی‌ها، مقایسه محصولات، کد تخفیف و اعلان‌های مشتری
- باشگاه امتیاز مشتریان و بازیابی سبدهای خرید رهاشده از طریق اعلان داخل حساب
- مدیریت تأمین‌کنندگان، سفارش خرید و ثبت رسید انبار
- مدیریت شرکت حمل، کد رهگیری و وضعیت ارسال
- بنرهای تبلیغاتی قابل مدیریت از پنل مدیر
- گزارش و خروجی Excel (.xlsx) و CSV از محصولات، سفارش‌ها و مشتریان
- هشدار کالاهای کم‌موجود و ثبت سوابق عملیات مدیریتی
- دستیار هوشمند راهنمای خرید (با اتصال API اختیاری)

## تنظیمات محیطی
تنظیمات محرمانه را فقط در بخش Environment Variables هاست وارد کنید و هرگز در کد یا Git قرار ندهید.

متغیرهای اصلی موجود برنامه:
- `DATABASE_URL`
- `SECRET_KEY` (حداقل ۳۲ کاراکتر تصادفی)
- `ADMIN_USERNAME` و `ADMIN_PASSWORD`
- `ZARINPAL_MERCHANT_ID` و `ZARINPAL_SANDBOX`
- `GHASEDAK_API_KEY` و در صورت نیاز `GHASEDAK_LINE_NUMBER`

برای فعال شدن دستیار هوشمند:
- `OPENAI_API_KEY` (الزامی)
- `OPENAI_MODEL` (اختیاری؛ پیش‌فرض `gpt-4o-mini`)
- `OPENAI_BASE_URL` (اختیاری؛ پیش‌فرض API رسمی OpenAI)

بدون کلید API هوش مصنوعی، صفحه دستیار نمایش داده می‌شود اما پاسخ‌گویی AI فعال نخواهد بود. کلید را در متغیرهای امن هاست ثبت کنید.

## اجرای محلی
```bash
pip install -r requirements.txt
gunicorn app:app --bind 0.0.0.0:$PORT
```

ساختار پایگاه داده به‌صورت افزایشی ایجاد می‌شود؛ جداول جدید با `CREATE TABLE IF NOT EXISTS` اضافه می‌شوند و اطلاعات فعلی محصولات، قیمت‌ها، مشتریان، سفارش‌ها و تنظیمات پرداخت نباید پاک یا بازنویسی شوند.
