# فروشگاه لوازم خانگی
نمایش قیمت و محصولات فروشگاه لوازم خانگی 
تمام سورس کد ها با html -css -phyton هست 


## امکانات فروشگاه و وظایف زمان‌بندی‌شده

- اعتبار کارت هدیه هنگام checkout از مبلغ سفارش کم می‌شود. برای سفارش ناموفق زرین‌پال یا لغو مجاز سفارش، اعتبار مصرف‌شده به کارت بازگردانده می‌شود.
- هشدار کاهش قیمت از طریق سرویس پیامک قاصدک ارسال می‌شود. برای فعال شدن بررسی خودکار، باید در زمان‌بند هاست یک درخواست POST دوره‌ای به مسیر `/internal/price-alerts/run` ارسال شود.
- هر دو وظیفه پیامکی داخلی با متغیر محرمانه `SMS_CRON_SECRET` محافظت می‌شوند. مقدار آن باید حداقل ۳۲ کاراکتر تصادفی باشد و در هدر `Authorization: Bearer <SMS_CRON_SECRET>` ارسال شود.
- ارسال هشدار قیمت به `GHASEDAK_API_KEY` و شماره خط پیامک تنظیم‌شده در پنل پیامک نیاز دارد. بدون تنظیم این موارد، پیامکی ارسال نمی‌شود.
- پیشنهاد زمان اجرا: هر ۱۵ دقیقه یک بار. از قراردادن کلیدها در کد یا مخزن GitHub خودداری کنید.
- این مسیر زمان‌بندی را اجرا می‌کند اما زمان‌بند را در هاست ایجاد نمی‌کند؛ فعال‌سازی Cron در پنل هاست یک مرحله جداگانه است.
